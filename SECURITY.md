# 🔒 Security Policy

## 📌 Supported Versions

This project is under active development.  
Security updates are applied to the latest version.

| Version | Supported |
|--------|----------|
| Latest | ✅ Yes |
| Older versions | ❌ No |

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

### 📬 Contact

- Email: luckyudbhav@gmail.com 
- (Optional) GitHub Issues: [https://github.com/Udbhav-regadamilli/RAG-based-AI-Chatbot-for-PDF-Q-A/issues ](https://github.com/Udbhav-regadamilli/RAG-based-AI-Chatbot-for-PDF-Q-A/issues)

> ⚠️ Please avoid reporting sensitive vulnerabilities in public issues.

---

## 🛡️ What to Include in Your Report

To help us resolve issues quickly, include:

- Description of the vulnerability  
- Steps to reproduce  
- Potential impact  
- Suggested fix (if any)  

---

## ⏱️ Response Time

- Initial response: within **48–72 hours**  
- Resolution time: depends on severity  

---

## 🔐 Security Best Practices

When using this project:

- Do not expose sensitive data in PDFs  
- Run the system in a secure environment  
- Restrict access to local LLM endpoints (`Ollama`)  
- Avoid running with untrusted inputs in production  
- Keep dependencies up to date  

---

## ⚠️ Known Considerations

- This project processes entire PDFs in memory  
- No built-in authentication/authorization layer  
- Designed primarily for local/offline usage  

---

## 🚫 Scope

This project does NOT currently handle:

- Multi-user authentication  
- Access control mechanisms  
- Encrypted storage  

---

## 🤝 Responsible Disclosure

We appreciate responsible disclosure and will:

- Acknowledge valid reports  
- Work on fixes promptly  
- Credit contributors (if desired)
